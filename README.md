# Walid Voyages — Omra 36 mois ULTRA

Preview locally by opening `index.html`.

## Features
- Hero cinematic Kaaba
- Tunisian green passport visual
- WALID INFO animated news ticker
- Animated 0 → 36 counter
- Glass / travel-tech UI
- Scroll reveal animations
- Parallax / mouse 3D passport
- Financing section
- Wifak Bank / Bank Zitouna section
- Responsive mobile bottom dock
- Official Walid Voyages CTAs

## Before GitHub
The Kaaba and passport visuals are loaded from external image URLs. For production, you can later download/licence your preferred final photos and put them in `assets/` so the page is fully self-contained.
